# Stage-1 pre-training corpus (optional)

Put your own text here **before** running bootstrap:

- `*.txt`: documents separated by blank lines
- `*.jsonl`: one `{"text": "..."}` per line

Nothing in this folder is downloaded automatically. Without files here TwinSim pre-trains on the
synthetic development corpus generated by `data/synthetic.py` (labelled as synthetic everywhere).
Check the licence of any corpus you add (e.g. TinyStories).
